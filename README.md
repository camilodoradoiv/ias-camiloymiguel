# IA Distributiva de Machine Learning — Ejecución Directa

Este paquete unificado contiene toda la aplicación en un único archivo (`app.py`) que **abre directamente la página web interactiva en tu navegador** al presionar el botón **Ejecutar (▶)** en Visual Studio Code o cualquier editor de Python.

## Ventajas de esta versión
- **Cero instalaciones (`pip install`)**: Utiliza únicamente la librería estándar incluida en Python.
- **Sin comandos en terminal**: Solo abre `app.py` en Visual Studio Code y haz clic en el botón **Ejecutar (▶)** arriba a la derecha.
- **Apertura automática**: Al ejecutarse, lanza un servidor local instantáneo y abre automáticamente tu navegador con toda la interfaz interactiva, topología de circunferencias, los 3 macroprocesos (Aeropuerto, Casa Constructora y Policía), etiqueta multimodal y asistente de voz integrado.
